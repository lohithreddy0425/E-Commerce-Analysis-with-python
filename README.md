# E-Commerce Sales Analysis 📊

## 📌 Project Overview

This project analyzes e-commerce sales data using Python to identify sales trends, monthly profit performance, and customer segment insights. Data analysis and visualization help understand business performance and support data-driven decision-making.

## 🎯 Objectives

* Analyze sales and profit performance.
* Identify monthly profit trends.
* Compare sales and profit across customer segments.
* Create visualizations to understand business insights.
* Practice data analysis using Python.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Plotly
* Jupyter Notebook

## 📈 Key Analysis

* **Monthly Profit Analysis:** Calculates and visualizes total profit by month.
* **Sales and Profit by Customer Segment:** Compares sales and profit across customer segments.
* **Data Exploration:** Examines order dates, customer information, product categories, sales, and profit.

## ⚙️ How to Run the Project

1. Clone or download this repository.
2. Install the required Python libraries:

   ```bash
   pip install pandas numpy plotly jupyter
   ```
3. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```
4. Open the project notebook.
5. Run the cells in order to perform the analysis and generate visualizations.
